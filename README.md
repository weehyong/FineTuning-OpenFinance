# FineTuning-OpenFinance

This repository contains two end-to-end Python tutorials for fine-tuning Qwen3 into an open-finance assistant using Unsloth + LoRA.

## What is in this repo

- `openfinance-eg2.py`
  - Tutorial script for **Qwen3-0.6B**
  - Uses a smaller sample set (`total_samples=2000`) for faster experimentation
- `openfinance-eg2-8B.py`
  - Tutorial script for **Qwen3-8B**
  - Uses a larger sample set (`total_samples=20000`) and 8B-oriented LoRA settings

Both scripts walk through the same pipeline:
1. Load a base instruction-tuned model with Unsloth
2. Attach LoRA adapters
3. Build a mixed training dataset (finance, translation, general, RAG, math/code)
4. Format chat examples
5. Train with TRL `SFTTrainer`
6. Run sample inference tests
7. Save the fine-tuned adapter

## Prerequisites

- Python 3.10+
- NVIDIA GPU with CUDA (strongly recommended)

Install core dependencies:

```bash
pip install --upgrade unsloth unsloth_zoo
pip install datasets trl transformers huggingface_hub torch
```

## How to run

From the repository root:

```bash
python openfinance-eg2.py
```

or

```bash
python openfinance-eg2-8B.py
```

## Outputs

Each script saves adapter artifacts to:

- `./qwen-open-finance-output/`

This folder contains the trained adapter and tokenizer files generated by `save_pretrained`.

## Notes

- These scripts are educational, end-to-end tutorials and include extensive inline explanations.
- Training time and memory usage vary significantly by model size and GPU.
- Dataset downloads are pulled dynamically from Hugging Face at runtime.
